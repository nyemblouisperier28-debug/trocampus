🚀 Installation et Lancement



Prérequis

SDK .NET configuré avec la charge de travail MAUI (`dotnet workload install maui`)\[cite: 1].



Étapes de lancement

1\. Cloner le dépôt :

&#x20;  ```bash

&#x20;  git clone \[https://github.com/nyemblouisperier28-debug/trocampus.git](https://github.com/nyemblouisperier28-debug/trocampus.git)

2\. Restaurer les dépendances :
